# Artificial Intelligence for Data Scientists

This repository contains my coursework, assignments, practical exercises, notes, and artificial intelligence projects for the **Artificial Intelligence for Data Scientists** course.

The course covers artificial intelligence and deep learning concepts, image classification using Artificial Neural Networks (ANN) and Convolutional Neural Networks (CNN), model optimization and evaluation, object detection, computer vision, and data-driven analysis using artificial intelligence techniques.

## Learning Objectives

Through this course, I developed skills in:

* Understanding fundamental concepts and applications of Artificial Intelligence for data science.
* Understanding the principles of neural networks and deep learning.
* Preparing and preprocessing image datasets for machine learning and deep learning tasks.
* Implementing Artificial Neural Networks (ANN) for image classification.
* Designing and implementing Convolutional Neural Networks (CNN) for image classification.
* Understanding CNN components, including convolutional layers, filters, feature maps, pooling, and fully connected layers.
* Applying training and optimization techniques to improve model performance.
* Evaluating classification models using appropriate performance metrics.
* Comparing ANN and CNN models based on accuracy, training time, model complexity, and generalization ability.
* Applying computer vision techniques for object detection in traffic video data.
* Detecting and classifying vehicle objects using Artificial Intelligence models.
* Processing video data and generating bounding boxes, object categories, and confidence scores.
* Evaluating object detection models using metrics such as precision, recall, F1-score, and mean Average Precision (mAP).
* Analyzing vehicle detection results using statistical summaries, tables, and visualizations.
* Interpreting patterns in traffic data based on the results of Artificial Intelligence models.
* Making data-driven decisions based on the analysis and evaluation of Artificial Intelligence models.
* Documenting and communicating Artificial Intelligence workflows, results, and limitations.
